# Yummy – What to Eat

Yummy is a web/mobile application that helps users decide what to eat based on meal categories, preferences, and excluded products.

## Features
- Meal category selection
- Food recommendations
- Excluded-product handling
- Ingredient replacement logic
- Ukrainian and English interface

## Tech
- Expo
- Capacitor
- JavaScript / TypeScript
- Vercel

## About
Built independently from concept to deployment as a personal software project.
