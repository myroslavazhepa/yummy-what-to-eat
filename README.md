# Yummy – What to Eat

Yummy is a web application that helps users decide what to eat based on meal categories, personal preferences, and excluded products.

## Features

- Meal category selection
- Food recommendations
- Excluded-product handling
- Ingredient replacement logic
- Ukrainian and English interface
- Responsive web experience

## Tech Stack

- TypeScript
- React
- TanStack Start
- TanStack Router
- TanStack Query
- Vite
- Tailwind CSS
- Radix UI
- Cloudflare tooling

## Project Structure

The application is organized into reusable components, routes, hooks, utility modules, and server-side logic.

Main folders include:

- `src/components`
- `src/routes`
- `src/hooks`
- `src/lib`

## About the Project

I designed and built Yummy independently from concept to deployment.

The project helped me practice:

- product thinking
- frontend development
- web application architecture
- debugging and testing
- UI/UX iteration
- AI-assisted development workflows

The application was tested by several early users and improved based on their feedback.
